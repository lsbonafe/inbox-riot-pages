# Visual references

Three original generated artworks illustrating Inbox Riot’s physical-collage direction: photographic cutouts, printed grain, torn paper and compositions that connect related subjects. These examples were created from fictional demo scenarios.

Inspect and attach the actual PNGs as style inputs to an image generator. Transfer the medium and compositional principles; create fresh artwork for each new album rather than reusing these images as its cover. Keep titles in HTML.

[manifest.json](manifest.json) records each file’s SHA-256 and visual notes. A private instance can select these references through its own pack and direct download URLs. Verify downloaded bytes against that instance’s approved hashes before attaching them. A filename or URL in prompt text does not attach an image.

These files follow the repository’s [MIT license](../../LICENSE). This directory contains artwork and style notes only, without private instance configuration, email content or credentials.
